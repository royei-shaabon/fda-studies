Combining multiple weighted criteria + ranking

Real scoring almost always combines several criteria, often with different weights reflecting how much each one matters. Let's add a second criterion and combine them properly.

typescript
function scorePassengerVolume(airport: Airport2): number {
  return airport.passengers / 1_000_000;
}

function scoreDelayPenalty(airport: Airport2): number {
  return airport.delayRatePercent;
}

function scoreAirport(airport: Airport2, weights: { volume: number; delay: number }): number {
  return (
    scorePassengerVolume(airport) * weights.volume -
    scoreDelayPenalty(airport) * weights.delay
  );
}

Notice scoreAirport now takes a weights parameter — this is important because it means your scoring logic is configurable, not hardcoded. This is exactly the kind of thing an interviewer will push on: "what if I told you delay matters twice as much as volume?" — and you should be able to answer that by changing a number, not rewriting the function.
