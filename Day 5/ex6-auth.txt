SDK + Auth Exercise

Everything through Day 5 used raw fetch calls with manually-typed request/response shapes. That's genuinely useful for understanding what's happening under the hood, but in practice you'll almost always use the official @anthropic-ai/sdk package — it handles auth headers, retries, and gives you typed response objects out of the box.

A few things to know before you write this:

Install: npm install @anthropic-ai/sdk
Client setup:
typescript
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});
Note: apiKey: process.env.ANTHROPIC_API_KEY — this is actually the default behavior if you omit apiKey entirely (the SDK looks for ANTHROPIC_API_KEY in the environment automatically), but writing it explicitly is worth doing once so you understand what's happening rather than relying on invisible magic.
The call itself: anthropic.messages.create({ model, max_tokens, system, messages }) — same shape you've already built by hand, just handled by the SDK now.
The response object's content field is typed by the SDK itself — it's not any from a raw .json() call anymore. You'll still need to narrow which block type you're looking at (text vs. tool_use etc.), but the SDK gives you real types to narrow against instead of unknown.
