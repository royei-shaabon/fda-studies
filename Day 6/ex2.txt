2 proper — tool schemas next.

Before the mechanics: a tool schema is how you describe a function to the model — its name, what it does, and what arguments it takes — so the model can decide when to "call" it and generate correctly-shaped arguments. The model never sees your actual TypeScript function; it only sees this description.

Question before I show you the shape: given that the model can only work from a text/JSON description of your function, not the function itself — what do you think happens if that description is vague, e.g. a parameter just described as "the amount" with no type or constraint, versus one described precisely as "amount: a positive number representing the charge in USD cents"? Concretely, what goes wrong with the vague version, and where in the tool-call loop would that failure actually surface?
